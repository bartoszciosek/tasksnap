# TaskSnap

TaskSnap is a simple and responsive full-stack task management application (To-Do). The project combines a modern Angular frontend with a Java backend, fully containerized for a quick setup using Docker.

## Tech Stack

* **Frontend:** Angular (Standalone Components, Signals, Inline Styles)
* **Backend:** Java / Spring Boot (Gradle)
* **Containerization:** Docker / Docker Compose

---

## Getting Started

### 1. Quick Start (Docker)
